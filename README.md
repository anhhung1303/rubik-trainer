# Rubik Trainer

Look up F2L, OLL and PLL algorithms by showing what your cube looks like, then watch them in 3D.

- **F2L**: browse all 41 cases as 3D previews and pick yours to see how to insert the pair into the front-right slot.
  Practice mode shows a random case with the algorithm hidden until you reveal it.
- **OLL**: tap the yellow stickers of your last layer to get the matching case (all 57).
- **PLL**: browse all 21 cases as 3D previews, with the same practice mode as F2L.

## Run

```bash
npm start
```

Then open http://localhost:8137 (`#f2l`, `#oll` or `#pll`).
No build step is needed; three.js loads from a CDN.

## Test

```bash
npm test
```

The tests run every algorithm on the cube model.
OLL algorithms must orient the last layer without breaking F2L.
F2L algorithms must solve the front-right pair without breaking the cross or the other slots, and the 41 cases must cover all 149 unsolved pair states.
PLL algorithms must fully solve the cube from every U-layer rotation.

## How it works

- `js/cube.js` is a sticker-based cube model that supports face, wide, slice and rotation moves.
- `js/oll.js` holds the 57 OLL algorithms.
- `js/f2l.js` holds the 41 F2L algorithms.
- `js/pll.js` holds the 21 PLL algorithms.
- Each case is generated by applying the inverse algorithm to a solved cube, so a case always matches its algorithm.
- OLL lookup tries all 4 U-layer rotations and adds the needed `U` turn.
- After playing an algorithm, the 3D cube returns to the starting case.
- Algorithms that leave the cube rotated (like Aa with `x`) get a final whole-cube turn in the demo so it ends upright.
- `js/player.js` and `js/viewer3d.js` render and animate the cube with three.js.
- `js/case-trainer.js` is the case browser shared by the F2L and PLL tabs; `js/oll-app.js` and `js/main.js` wire up the rest.
